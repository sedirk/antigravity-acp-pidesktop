服务与端点

PI-Desktop 里填 http://127.0.0.1:端口/v1
各位详细说明：
• all（全部放行）：不作拦截；工具执行与权限确认交由宿主卡片处理。
• shell（执行 + 只读）：允许跑 bash/powershell 命令与读文件，禁止写/改文件。
• agent（子任务 + 只读）：允许委派子代理与生图，杜绝弹出命令行窗口与写文件。
• search（纯只读）：仅允许联网搜索与查看文件，防止任何系统环境变动。
• none（纯对话）：完全拦截工具，降级为纯文本对话模式。

会话与超时

发送 ACP session/cancel 通知中止当前轮次，不会杀掉运行时，也不会丢失会话上下文
0 = 不设上限（推荐）。长任务可以一直跑，真正的止损是「无进展判定」。
连续这么久收不到任何进展才取消本轮；只要运行时还在报工具进展就不会被砍

高级与并发

设为 1 即串行：同一时刻只跑一条 prompt
上游 1.3.0 只在 clientInfo.name 为 Zed / Xcode / JetBrains 时才提供 Claude、GPT-OSS；填 Zed 即可看到
到点用 session/close 释放运行时的 worker；下次发言优先 session/resume 接回

工具与桥接

开启后运行时的工具调用会交给 PI-Desktop 执行（原生工具卡片、可调用 Task 子代理）；工具不再由运行时自己跑
每次发给运行时的提示会以这段开头；内置文案让它在阶段之间总体汇报进度，不必每调一次工具就解释一遍
运行时的文件工具（view_file / write_to_file）只认这个目录和 ~/.gemini；run_command 走系统权限、不受它限制。留空即可。
