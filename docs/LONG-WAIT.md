# 2.3.7：压缩前预算与慢首响

> 这是 2.3.7 的历史说明。2.3.8 不再显示浮条；当前的查数方式见 [原生菜单与数据口径](NATIVE-CONTEXT.md)。延长等待仍是独立的可选设置，不是本插件的依赖。

## 安装和使用

1. 在 PI-Desktop 的插件页导入 `local.antigravity-acp-2.3.7.piplug`。预算提示用到新增的 `agent.extension` 权限，需明确批准；它只读取宿主预算和本网关响应标记，写当前会话的 UI 状态，不改压缩决定、消息、模型绑定或系统文件。
2. 保存工作，并从托盘**退出** PI-Desktop（不是关闭窗口）。双击发行目录中的 `Start-PI-LongWait.cmd`。宿主不支持按 provider 单独配置超时；启动器使这一次启动的 PI 和其子代理的零模型事件等待从 180 秒变为 600 秒。它不会结束已有进程、写注册表或持久修改环境。只安装插件而用普通图标重开，仍是宿主原有的等待设置。
3. 网关还有单独的「无进展超时」，默认 300 秒，另有取消宽限。慢请求若确实超过该值，可在插件面板内显式调整（例如 480 秒，给宿主的 600 秒留出收尾时间）。设置为过大的值也会延迟真故障的提示。无需把看门狗关掉。

自定义安装位置可在新 PowerShell 窗口中执行以下命令（必须先退出旧实例，替换可执行文件路径）：

```powershell
$env:PI_DESKTOP_STREAM_IDLE_TIMEOUT_MS = '600000'
Start-Process 'C:\Program Files\PI-Desktop\PI-Desktop.exe'
```

回退：从托盘退出后用原图标启动，即恢复原来的宿主超时；需要回退插件时在插件页重新导入 2.3.6。旧会话无需删除；已写入的估算不会追溯改写。使用远端/独立 Host 的情况，应在真正运行 Agent 的进程上设置该参数，桌面启动器仅适用于本机 Host。

## 这次截图的两个百分比

上一检查点保留量 **38,177 / 256,000 = 14.9%**。这不是第 46 次压缩的触发量。宿主为完整历史、系统提示和工具做预算：256,000 减去预留输出 32,000 得到硬输入预算 224,000，自动线为 **201,600**。本次记录的 `tokensBefore` 为 **201,904**（整个窗口的 78.9%，硬输入预算的 90.1%）；本次完成后剩余估算为 **38,655**。压缩前最后一个 ACP 工具步的诊断值是 41,895 / 1,048,576，是另一层会话，不能拿来覆盖 PI 的完整请求预算。

当缺少可靠的逐步标准 usage 时，0.22 的原生圆环可能留在上个检查点。升级后看本网关会话的独立状态行，特别是「压缩前」；它读的就是宿主预算函数，不是网关自算的 token 或账单。本版不改原生环、不扩大 256K 窗口、不跳过超窗保护，也不承诺固定的工具次数。不同会话的阈值取决于各自的绑定、输出预留和压缩策略。

## 周期性断流的处理

宿主在解码后的模型事件之间计时。即使 TCP 正常，SSE 注释、Chat 空 delta、Responses 的 `in_progress` 也不是模型事件。网关仍可发送传输心跳，但不把倒计时伪装成模型思考。加长的是有限的宿主等待；显式停止仍立刻取消，真正无进展仍受网关和宿主看门狗保护。

2.3.6 的取消收尾会把 `base + pending` 提交为下次基线。在现场，重发一次就多算约 35,027。2.3.7 仅保留取消前已接受的水位，不采纳取消后迟到的用量、输出或未确认的估算。对于已回填的单工具纯文本结果，同一活会话重试只重送最后一份不确定的结果，不重放更早的大段回填。请求、所属会话或模型不匹配、并行批、附件等仍用既有恢复路径。
