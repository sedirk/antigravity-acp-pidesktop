# 输入框里的 ACP 会话读数（2.3.9，原版 PI 0.22.0）

导入插件并同意原有的 `agent.extension` 以及新增的 `renderer.extension`。继续使用原 PI 图标和已有本机 ACP 模型绑定；不需要宿主补丁、启动器、环境变量或斜杠命令。首次用此网关仍要按 README 下载并登录官方 ACP 运行时，选用指向它的模型。不会自动安装/改绑。

## 怎样读

- 工具栏按钮是**最近一次 ACP 请求对应的 PI 输入预算采样**。分子是 PI 对当时会话状态的 token 估算，分母是其硬输入限额（已预留输出空间）。这是对上限的占比，**不是距离自动压缩的百分比、不是计费、不是实时逐 token 计数**。原版不把决定压缩时所有待发内容、开关和触发线交给插件，因此不预测何时压缩，也不擅自标红一条固定线。
- 点开后的 **ACP 原始水位** 则取自同一次 HTTP 请求最近可归属的 `usage_update.used / size?`。有 `used` 无 `size` 就不算百分比；原始值可以降低，0 是 0；未报告不是 0。不要用上游窗口充当 PI 输入限额。原圆环/标准 usage/账本独立且未修改，两枚读数不必相等；**在连续多工具回交轮次中，网关按契约不伪造分腿标准 `usage`，宿主原生圆环会停留在此前最近一次单腿样本上不前进，长工具链期间请以本控件显示的 PI 输入预算估算与点击展开的 ACP 原始水位为准**。
- 确认响应头后、流中（预算至多每 5 秒采样）、消息/工具结束等事件会尝试更新。原始水位按网关实际收到的通知更新；它可能晚于最近的预算采样。详情列出预算采样的时间、来源服务和模型。收到 PI 的模型配置变更通知会撤下旧样本，等新绑定的合格新一轮请求恢复显示；这不是用来读取闲置模型选择器或草稿的接口。
- 切换话题或无法核对话题时隐藏。首次进入或冷开历史，需要本次运行的已确认回执，且当前页已有已挂载的完成态助手回复提供话题身份（首条回答仍在流式输出、尚无历史完成回复时暂不显示属正常保护）；当输入框容器处于极窄或特定折叠过渡宽度区间（`< 360px` 或 `450px–552px`）时也会让位给原生控件而自动隐藏。历史不会补录，原生圆环不存在不妨碍插件独立显示。工具回交、取消重试、压缩等无法归属时不借上一条；压缩前撤下读数，不以回调宣称“正在压缩”或“压缩成功”。回执最多十分钟、上限 512；过期、停止服务或重启会失效。

## 权限、隔离与关闭

工具栏使用宿主公开的渲染插槽；只有自有方法 `readContextMeter`，不读取草稿或消息正文，不注入宿主 DOM，不替换按钮。扩展只读 `getContextUsage()`；网关在自己的回执表核验归属。插件内部通过 OS 本机 IPC 传递少量标识及数字，不使用新 TCP 端口，不改模型 HTTP 请求/回包、工具调用、重试、账本或会话。只有随机 IPC 握手材料临时保存在按安装路径隔离的用户临时目录，不包含样本、聊天、模型凭据或授权头。样本仅在内存中使用。退出时作废通道，即使异常退出，重新启动也会换新随机值。

不授予渲染权限不会靠浮条替代；已有 Agent 扩展授权时仍可用 `/acp-context`。拒绝 Agent 扩展则无采样。要回退可重新导入保留的 2.3.8。此功能不改变原版 180 秒无模型事件保护，也不需要更改其他服务（例如学校 DS）。
