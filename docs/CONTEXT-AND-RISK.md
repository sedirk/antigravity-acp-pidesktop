## 有界保护，不承诺无限无损

`lib/context.js` 统一管理分类、裁剪、意图索引、文件清单与调用组，避免内存、落盘和摘要各自维护不同规则。

- 用户意图：最多 64 项、24,000 字符 / 32,000 UTF-8 字节。首项最多 6,000 字符，后续每项最多 1,200；优先保留开头与近期，超长项有省略标记。这不是全量历史备份。
- 子代理交付：最多 8 个完整单元、96,000 字符 / 112,000 字节。预算不足先淘汰较早单元，保护最新两个；不静默剪掉报告中段。超限返回 `CONTEXT_BUDGET_EXCEEDED`，需减少单次交付规模后重试。工具启动/等待结果也会占用单元。
- 摘要文件列表：每类最多 40 条、约 4,000 字符；附过滤数量说明。正文中的用户指定路径不受此过滤影响。
- 摘要输入：整体最多 108,000 字符 / 116,000 UTF-8 字节。先识别封装的对话与真人指令，再裁剪大工具输出；保护区合计仍超限时显式报错。
- 普通重放：系统提示与当前请求不按历史滑窗裁剪；历史摘要、意图和工具窗口有界。超大当前请求仍受 HTTP / 官方管道限制。
- `sessions.json` 在插件数据目录保存有界意图、近期交付和会话元数据，可能含项目文本；不是仅存哈希。足迹按现有 7 天未使用 / 最多 500 条规则淘汰，不应随公开问题报告或安装包上传。插件不主动读取或保存认证令牌；不要在对话中粘贴密钥。
- 上游会话恢复失败时保留本地意图与交付再重建；历史内容修改与系统更新同时发生时，分支清理优先。工具大参数有明确省略标记，最新调用组仍无法容纳时显式报错。
- 已在旧版本被截掉、且当前输入和保存的足迹中均不存在的内容，不能凭空恢复。仅缩短成完全相同的历史前缀、没有明确修订信息时，仍无法可靠区分回退与重试，不能保证隔离旧运行时历史；需要彻底隔离时请使用新话题。

## 窗口与用量的正确口径

1. `usage_update.used/size` 是上下文占用/容量，不是账号的 5 小时或每周余额。`PromptResponse.usage` 则含输出、思考及缓存等明细；两者不能直接混加。
2. 自动压缩由 PI-Desktop 决定。窗口减去输出预留和安全余量后才是可用预算；例如一次历史配置为 `hardLimit=872000`，90% 触发点为 `784800`，并非固定的“1M 到 90 万才压缩”。
3. 想保留原生窗口：获取模型列表后重新勾选模型，或手填 `1048576` / `1000000`，然后保存服务。想更早精简：在宿主模型高级设置中调到 `262144` / `200000`。下轮请求按保存后的配置计算，UI 可能滞后一轮。
4. 插件保留官方水位。一次历史 `256844 → 25328` 尚无足够证据区分真实上游精简与计量异常；本版只增加回落诊断，不强行钳成单调递增、不据此重建会话。
5. 没有最终官方输出统计时，按实际收到的正文、工具参数和思考文本估算，并标记 `output_estimated: true`。官方累计输出到达后只上报未计入的余额，避免 park 与 finish 重复累计。估算先行时无法追溯撤回宿主已记下的高估值。
6. 官方 `thoughtTokens=0` 且没有思考文本时，插件不能杜撰推理量。收到思考文本时可估算，但不是隐藏推理的真实计费。`estimated:false` 主要标识上下文取得官方依据，不应解释成全部分项均精确。

## ACP / 1M 与账号风险

**没有找到能证明“设为 1M 比 256K 更容易封号”的对照因果证据，也没有“官方 ACP 一律不会封号”的保证。** 大窗口通常意味着更多输入处理与配额消耗；窗口、速率限制、账号合规是不同问题。

可核查来源（2026-11-17 复核）：

- [Google Antigravity 附加条款](https://antigravity.google/terms) 与 [官方 ACP 文档](https://antigravity.google/docs/ide/extensions/acp)：以当前条款、订阅与官方支持范围为准。
- [Google AI Developers Forum：私人 ACP 客户端问题](https://discuss.ai.google.dev/t/personal-app-using-the-official-agy-acp-binary-with-google-ai-pro-permitted/198889)，2026-11-09 的答复明确限定：未修改的官方二进制、原生认证、单用户交互；不提取/代理/复用内部 OAuth token，不做无人值守后台自动化、多用户服务、自动轮换账号，也不把 `agy` 包装为另一个第三方编码 Agent 循环中的子 Agent；非第一方 IDE 场景限订阅内 Gemini 模型。该答复针对帖主描述的架构，不是对本插件全部功能或使用方式的合规认证。
- [Gemini CLI Discussion #20632](https://github.com/google-gemini/gemini-cli/discussions/20632)：标题及公开摘要讨论 Antigravity 封禁造成的账号访问中断。此处不据未完整核对的评论推导处罚范围、申诉次数或因果概率。
- [oh-my-pi Discussion #17950](https://github.com/can1357/oh-my-pi/discussions/17950)：公开标题/摘要记录其从旧凭据与流量伪装路径迁移到官方 ACP。迁移方向不是零风险证明。

本插件使用官方运行时并把认证留给官方二进制，但 OpenAI 端点、工具权限、第三方模型和子 Agent 编排的每一种组合并未获得上游授权保证。建议仅本机单用户交互使用，不公开转发服务，不绕过配额/权限限制；触发限制应停止相关调用、核对条款或联系官方，而非换账号规避。
